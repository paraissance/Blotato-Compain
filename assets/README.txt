ASSETS
======
cutouts/   Transparent PNG cut-outs of Jody (jody1..jody5.png). The Agent
           Broker Coach "Jody" designs rotate through these. To add more,
           drop more transparent PNGs in here named jody6.png, jody7.png, ...
fonts/     Modern fonts used on the cards (Montserrat + Poppins).

The object/house/keys/phone posts pull photos live from Pexels (needs
PEXELS_API_KEY in .env). The "simple" posts use no photo.
